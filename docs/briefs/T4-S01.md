# T4-S01 — 4E Canada-Only Landing Zone scaffold

Repo: td-4-cloud · Environment: td-4-cloud · Day: D1 · Time box: 60 minutes · Credit cap: $5

## Goal
Create everything Eojin needs to put guard-rails on a brand-new Azure subscription before anything is built in it: two policy parameter files that keep resources in Canada and require an `owner` tag, a custom role that can only read and start/stop virtual machines, a plain-English guide for a spending budget and a "someone got new permissions" alert, a sign-up guide for the Azure free account, and a diagram. Nothing in this session touches Azure; every file is something Eojin applies himself after the merge, in Azure Cloud Shell (portal → the Cloud Shell icon → Bash → "No storage account required"). A "landing zone" is the set of rules you set on a cloud account on day one so that mistakes and attackers both hit a wall.
